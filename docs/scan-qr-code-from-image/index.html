How to scan a QR code from an image on PC

Updated October 30, 2026

You can read a QR code from a saved picture, a screenshot or a copied image without a phone. A desktop QR code reader does it in a few seconds and keeps the image on your computer.

Scan a QR code from an image file

This works for pictures saved on your PC, such as a ticket, a poster or a photo someone sent you.

  1. Download the ZIP of QR Code Scanner for PC, extract it and run the app.
  2. On the Read screen, click Image File and choose the picture.
  3. Read the decoded result. Check any link before you open it.

Scan a QR code from a screenshot or copied picture

If the code is on a web page or in an email, you do not need to save it first.

  1. Press Windows + Shift + S and select the area around the QR code. Windows copies the capture to the clipboard.
  2. Open QR Code Scanner for PC and click Clipboard Image.
  3. Read the decoded result.

You can also copy an image directly from your browser and read it the same way.

Scan QR codes from many images at once

If you have a batch of images, click Folder and select the folder that holds them. All the codes in the folder are decoded at once, so you do not have to open each file.

What to do if the QR code will not scan

Crop tighter

Capture only the code and a small white margin around it. Other objects in the picture can get in the way.

Use a larger image

A small or heavily compressed picture can lose the fine squares of the code. Find the original, or zoom in before you take the screenshot.

Fix contrast and angle

A dark, glaring or strongly tilted photo is harder to read. Retake it straight on in even light if you can.

Check that the whole code is visible

The three large corner squares must all be in the image, and the code cannot be cut off at the edge.

Common questions

Can you scan a QR code from a photo on a computer?

Yes. Save the photo to your PC and open it in a QR code reader, or copy the picture and paste it.

Can you scan a QR code from a screenshot?

Yes. A screenshot is an ordinary image, so you can paste it from the clipboard or open the saved file.

Is it safe to scan a QR code from an image online?

An online reader may send your image to its server, depending on the site. If the code holds something private, such as a Wi-Fi password or a login link, a desktop reader avoids that because it runs on your PC.
