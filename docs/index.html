A free QR code reader for your PC or laptop. Scan codes from your screen, an image or a webcam, and keep everything on your computer.

Read a code wherever you find it

Most QR codes on a computer are already on the screen or saved in a file, so you rarely need a phone to read them.

On your screen

Click Snipping Tool, select the area with the code and it is decoded right away. It works for codes in a browser, an email or a document.

In an image or screenshot

Click Image File or Clipboard Image. Use it as a QR code reader for pictures you were sent or saved. How to scan a QR code from an image.

With a laptop camera or webcam

Click Webcam and hold a printed code up to your camera. The scanner also takes video from an OBS virtual camera or the Windows Camera app.

In a whole folder

Click Folder to decode every image in it at once, which saves opening each file when you have a batch to process.

How to use the QR code reader on your PC

  1. Download the ZIP from SourceForge, extract it and run the app. There is nothing to install.
  2. On the Read screen, choose where the code is: Snipping Tool, Clipboard Image, Image File, Folder or Webcam.
  3. Check the decoded result, then use Copy to keep it or Launch to open it.

A barcode scanner for PC, too

It decodes 17 barcode types from the same screen, image and camera sources, so you do not need a USB scanner to read a barcode on your computer.

Read and create

QR Code, Code 128, Code 39, EAN-8, ITF, UPC-A, UPC-E, Codabar, Data Matrix, PDF417, Aztec, MSI and Plessey.

Read only

MaxiCode, RSS-14, RSS Expanded and EAN-13.

Create QR codes as well

The Create screen makes QR codes from any text, with ready templates for Wi-Fi, email and contact cards. You can change the colors, margins and error correction level.

What you enter is exactly what gets encoded, with no redirect link added to your code.

Your codes stay on your PC

Processed locally

Scanning and generating happen on your computer, and no network connection is needed to use them.

Check links before opening

See the full contents of a QR code first, so you can spot a suspicious link before you visit it.

History you control

View and export the codes you scanned and created, or turn history off.

Frequently asked questions

Is this QR code scanner really free?

Yes. It is freeware with no paid version, and the source code is published under the Apache 2.0 license.

Does the scanner work offline?

Yes. It reads and creates codes on your PC without a network connection.

Do I need to install it?

No. It is a portable app: download the ZIP, extract it and run the program.

Do I need a webcam to scan a QR code on my PC?

No. A webcam is only needed for camera scanning. You can also read codes from your screen, an image file or a picture copied to the clipboard.

Are my images uploaded anywhere?

No. Images are processed locally, and decoded or generated data is not collected.

Can it read a QR code from a screenshot?

Yes. Paste the screenshot from the clipboard or open the saved file. The image guide covers each way.

Which versions of Windows are supported?

Windows 10 and Windows 11, 64-bit. There is no Mac or Linux version.

Which barcodes can it read?

17 types, including QR Code, Code 128, Code 39, EAN-13, UPC-A, Data Matrix, PDF417 and Aztec.
